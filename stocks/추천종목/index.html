찾는 대상아직 AI 대표주로 덜 인식된 후속 수혜주 후보
핵심 병목CPU·메모리·네트워크·광통신·전력
주의‘소외주’ 여부는 현재 밸류에이션과 주가 선반영 확인 필요

이 리서치를 이렇게 정리한 이유

AI 투자가 GPU와 HBM에 집중된 뒤, 실제 데이터센터를 돌리는 과정에서 다른 병목이 드러나고 있다. 이 문서는 그 ‘다음 병목’에서 수혜가 생길 수 있는 종목을 찾는 지도다.

1
GPU만 늘어도 CPU·서버 DRAM·SSD·네트워크·전력 사용량이 함께 증가한다.
2
그래서 AI 대표주가 아닌 테스트·기판·광통신·전력주까지 실적 수혜가 번질 수 있다.
3
다만 ‘좋은 산업’과 ‘지금 싼 주식’은 다르므로 마지막에는 실적·PER·주가 선반영을 따로 확인해야 한다.
한 줄 투자 논리
GPU→CPU→Test→DDR5·SSD→PCB·Package→Network·Optical→Power·Cooling
섹터대표 후보핵심 병목
CPU·테스트AMD, ISC, 리노공업에이전트 제어 + 고사양 칩 검사
메모리·SSDSK하이닉스, 삼성전자, Micron작업 메모리 + Context 저장
기판·MLCC이수페타시스, 삼성전기, 대덕전자고속 신호 + 전력 안정화
패키징한미반도체, 하나마이크론, TSMC이종 칩 집적 난도
네트워크AVGO, MRVL, ALAB, CRDO, ANET데이터 이동량 폭증
전력·냉각LS ELECTRIC, VRT, ETN전력 공급과 열관리
※ 위 표는 ‘테마 연결 구조’ 요약이다. 현재 주가 매력도 순위는 아니다.
1

CPU · AI칩 · 테스트

에이전트가 많아질수록 CPU의 오케스트레이션 부담과 고성능 칩 테스트 수요가 함께 증가.

CPU 본체 미국
AMD AMD
직접 수혜
EPYC 서버 CPU. Agentic AI의 CPU 연산·오케스트레이션 확대 논리.
Intel INTC
Xeon 서버 CPU. AI 서버와 일반 서버 CPU 수요 회복이 핵심.
ARM ARM
데이터센터 CPU 아키텍처 변화와 저전력 서버 확산 수혜.
테스트 부품 국내
ISC
CPU·GPU·AI칩 테스트 소켓. 검사 횟수와 난도 증가의 간접 수혜.
리노공업
테스트 핀·소켓. 고사양 반도체의 검사 정밀도와 복잡도 증가에 연결.
두산테스나 — 테스트 섹터 보충 설명
눌러서 두산테스나의 역할과 체크포인트를 자세히 볼 수 있어요.
정체성
시스템반도체 웨이퍼 테스트 서비스. ISC·리노공업처럼 소켓을 파는 회사가 아니라 칩을 직접 검사하는 회사.
기존 사업
모바일 AP · CIS · 자동차 반도체 · 일반 시스템반도체 테스트.
변화 방향
서버용 컨트롤러 → AI/HPC SoC 테스트 → 고사양 시스템반도체 비중 확대.
핵심 시점
2026년-4분기 AI용 SoC 테스트 매출 시작 기대 → 2027년 증설·가동률 효과 확인.
장점
AI 매출이 이미 완성된 회사라기보다 이제 붙기 시작하는 초기 단계라는 점.
리스크
삼성 계열 의존도, 증설 이후 가동률, AI 매출 전환 속도.
봐야 할 숫자
AI SoC 매출 → 2027년 가동률 → 영업이익률 → 신규 고객·신규 칩.
테스트 섹터를 한 번에 구분하면?
ISC = 소켓 / 리노공업 = 핀·소켓 / 두산테스나 = 실제 웨이퍼 테스트 서비스 / Advantest = 테스트 장비. 두산테스나는 중요한 보충 후보지만 현재 이 테마의 대표주처럼 과도하게 강조할 필요는 없다.
2

메모리 · 서버 DRAM · SSD

Agentic AI는 ‘추론’뿐 아니라 많은 작업 상태와 Context를 오래 유지해야 해서 HBM 밖의 메모리와 저장장치 중요도가 올라감.

메모리 종합 수혜 HBM만 보면 부족
SK하이닉스
HBM + DDR5 + 서버 DRAM + eSSD. Agentic AI에서 수혜 범위가 가장 넓은 국내 메모리 후보 중 하나.
삼성전자
HBM + DDR5 + 서버 DRAM + NAND + Enterprise SSD. 범용 메모리 회복까지 동반되면 수혜 폭 확대.
Micron MU
HBM + DDR5 + Server DRAM + NAND + Enterprise SSD. GPU Rack + CPU Rack + Storage Rack 논리를 한 종목에서 볼 수 있음.

MLCC · 전력 안정화
삼성전기

네트워크 · Interconnect · 광통신

이번 Agentic AI 사이클에서 특히 새롭게 봐야 할 핵심. 데이터 이동량이 연산량 못지않게 빠르게 늘어남.

투자 판단 전에 반드시 볼 것
좋은 산업과 좋은 매수가격은 다르다. 각 종목의 현재 주가, 최근 상승률, Forward PER, 2026년-2028년 EPS 성장률, AI 매출 비중, 실제 AI 매출 발생 여부, 주가 선반영 정도를 따로 확인해야 한다.
이 페이지는 2026-09-23까지의 대화에서 정리한 산업 구조와 공개 자료 기반 아이디어를 모바일용으로 재구성한 리서치 노트입니다. 실제 투자 전에는 최신 실적·밸류에이션·수주·가동률을 다시 확인하세요.
