# 맛집 레이더

동네 음식점·카페를 **전부** 모아서 보여주고, 네이버 블로그·카페 리뷰를 **AI(Claude)가 대신 읽고 평점**을 매겨 주는 모바일 웹앱입니다.
핸드폰 브라우저에서 열고 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있어요.

## 기능

- **서울·경기 전체**: 서울 25개 구, 경기 31개 시·군 어디든 검색할 수 있어요. 위치 줄을 누르면 구·시를 골라 이동합니다.
  - **이 동네**: 반경(300m~5km) 안의 음식점·카페를 유명한 곳만이 아니라 모두 가져옵니다 (카카오 로컬 API).
  - **서울·경기 전체**: 테마(뷰 카페 등)나 메뉴 검색(평양냉면, 오마카세…)을 구·시마다 돌려서 서울·경기 전역에서 찾아요.
- **검색창**: 동네 이름(성수동, 판교)을 넣으면 그 동네로, 메뉴 이름(평양냉면)을 넣으면 그 메뉴 파는 집을 찾아요.
- **사진**: 카드마다 사진, 가게를 누르면 맨 위에 사진 12장 갤러리 (누르면 크게 보기).
- **대표 메뉴**: 리뷰에서 가장 많이 추천된 순서로 메뉴 사진·가격·추천 이유를 크게 보여주고, 카드에도 1등 메뉴가 표시돼요.
- **카테고리**: 한식·고기·해산물·중식·일식·양식·아시안·분식·치킨·술집·카페
- **테마**: 부모님과 / 뷰 좋은 카페 / 눈이 즐거운 카페 / 주차 편한 곳
- **AI 리뷰 평점**: 블로그·카페 리뷰 최대 30개를 읽고 5점 만점 점수, 한 줄 평, 장단점, 대표 메뉴. 광고·협찬 의심 글은 덜 반영합니다.
- **주차 여부**와 **브레이크타임**: 리뷰에서 찾아 크게 표시합니다.
- **근처 주차장**: 700m 안의 주차장을 공영주차장 먼저 보여줍니다.
- **지도**: 목록을 지도로 보기, 가게를 누르면 지도 + 주변 주차장 표시.
- **바로가기**: 네이버 지도(네이버 평점·방문자 리뷰), 카카오맵(카카오 평점), 길찾기, 인스타 해시태그, 전화.

키가 없으면 **샘플 데이터**로 화면만 볼 수 있어요.

## 필요한 키 (Netlify 환경 변수)

Netlify → Site configuration → Environment variables 에 넣습니다.

| 변수 | 어디서 받나 | 용도 |
|---|---|---|
| `KAKAO_REST_KEY` | [Kakao Developers](https://developers.kakao.com) → 앱 만들기 → 앱 키 → **REST API 키**. 앱 설정에서 **카카오맵** 사용을 켜야 합니다. | 가게 목록, 동네 검색, 주차장 |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | [NAVER Developers](https://developers.naver.com/apps) → 애플리케이션 등록 → 사용 API **검색** | 블로그·카페 리뷰, 카드 사진 |
| `ANTHROPIC_API_KEY` (선택, 유료) | [Claude Console](https://console.anthropic.com) | 넣으면 Claude가 리뷰를 읽어요. **안 넣으면 무료 키워드 분석**으로 동작해요. |
| `APP_PASSCODE` (선택) | 아무 비밀번호 | 넣으면 처음 한 번 비밀번호를 물어봐요. 남이 내 API 비용을 쓰지 못하게 막습니다. |
| `CLAUDE_MODEL` (선택) | 기본 `claude-opus-5-5` | `claude-haiku-5-5`로 바꾸면 훨씬 싸고 빠릅니다. |

키를 넣은 뒤 **다시 배포**(Deploys → Trigger deploy)해야 적용됩니다.

## 완전 무료로 쓰기 (개인용)

카카오·네이버 키만 넣으면 **0원**으로 전부 돌아갑니다.

- Netlify 무료 플랜, 카카오 로컬 API, 네이버 검색 API 모두 무료예요 (개인이 쓰는 양이면 일일 한도에 닿지 않아요).
- 리뷰 점수는 **무료 키워드 분석**이 매겨요. 칭찬·불만 표현을 세고, 협찬 글은 덜 반영하고, 가격이 붙은 메뉴와 주차·브레이크타임 문장을 찾아요.
- 무료 분석은 Claude보다 거칠어요 (반어법이나 문맥은 못 읽어요). 나중에 더 정확하게 보고 싶으면 `ANTHROPIC_API_KEY`만 추가하면 바로 Claude로 바뀝니다. Claude Pro 구독과 API는 별도 결제예요.
- `APP_PASSCODE`를 걸어 두면 링크가 새도 남이 내 무료 한도를 쓰지 못해요.

## 한계

- **인스타그램, 네이버 지도 평점**은 공개 API가 없어서 직접 긁어오지 않습니다(약관 위반). 대신 버튼으로 바로 열 수 있게 했어요.
- AI는 검색 API가 주는 **리뷰 발췌문**(글 앞부분 요약)을 읽습니다. 글 전체를 읽는 건 아니에요.
- 주차·브레이크타임은 리뷰에 언급된 경우에만 나옵니다. "리뷰에 언급 없음"이면 전화로 확인하세요.
- 주차장 **요금**은 API로 받을 수 없어서, 보통 저렴한 공영주차장을 먼저 보여주고 상세 링크로 연결합니다.
- 분석이 시간 초과로 실패하면 `CLAUDE_MODEL=claude-haiku-5-5`로 바꾸세요 (Netlify 함수 기본 제한 10초).

## 로컬에서 실행

```sh
npm install
# .env 파일에 위 키들을 KEY=값 형식으로 적기
npm run dev   # http://localhost:8888/matjip/
```

## 파일

- `matjip/` — 화면 (HTML/CSS/JS, 빌드 없음)
- `netlify/functions/` — API 키를 숨겨 주는 서버 함수 (`places`, `reviews`, `analyze`, `parking`, `image`, `status`)
- `dev-server.mjs` — 로컬 실행용 서버
